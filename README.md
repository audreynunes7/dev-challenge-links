# dev-challenge-links
Este repositório é uma curadoria de plataformas, sites e desafios de programação encontrados na internet. O objetivo é centralizar os lugares para praticar em todos os níveis.

#### 💡 Como contribuir
Se você conhece algum site que não está na lista, sinta-se à vontade para abrir uma Issue ou enviar um Pull Request!

#### Legenda:
🟢 Gratuito

🟡 Freemium (Grátis com extras pagos)

Atenção: Nem todos os sites foram testados.
